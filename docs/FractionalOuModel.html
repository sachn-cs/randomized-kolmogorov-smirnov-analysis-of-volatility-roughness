Class: FractionalOuModel

(abstract) FractionalOuModel()

Abstract base class for the Fractional Ornstein-Uhlenbeck model. dX_t = theta (mu - X_t) dt + sigma dB^H_t Concrete subclasses pick the discretization scheme: - EulerMaruyamaFractionalOuModel — default, cheap - ExactFractionalOuModel — Riemann-Liouville integral, accurate
